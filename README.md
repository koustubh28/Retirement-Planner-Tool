📈 Projected Retirement Savings

A simple data visualization project that models and displays how retirement savings evolve over time based on contributions, returns, and withdrawals.

⚙️ Assumptions
The model is based on the following inputs (customizable):
  Initial savings
  Annual contribution
  Annual withdrawal (post-retirement)
  Expected rate of return
  Inflation rate (optional)
  Retirement age

  📌 Key Insight

This model demonstrates that:

Even strong early growth can be undone by unsustainable withdrawal rates.

If savings fall below zero, it indicates a shortfall in retirement planning.
